CASE / 01部署已完成 · Demo 脱敏

视觉道路监测：模型服务与媒体工作流

在双 RTX A5000 上完成 Qwen3-VL-8B 的 vLLM 私有化部署和接口联调；将图片、短视频输入整理为可复核的视觉推理请求。

  • 仍在验证：双模型复核、真实 Dify 编排效果与视频稳定性；没有公开可归因的吞吐、延迟或加速数据。

CASE / 02作业与一致性已验证

多晶石墨烯 PFC：大网格仿真与 GPU/HIP 验证

用 C11、FFTW 与 OpenMP 组织两阶段 PFC 密度场求解，并在 Slurm 管理的 GPU/HIP 计算环境完成 3456 × 2304 网格作业。

  • 计算流程：随机成核与生长、阶段结果重载及松弛；输出密度场快照、Extended XYZ 坐标和诊断图像。
  • 可靠性：对照 CPU 与 HIP 数值结果，记录阶段输入、日志和校验清单；用 smoke test 与 CI 覆盖求解及输出格式。
  • 经验边界：这里展示的是超算环境中的作业与验证经验；不宣称平台运维、分布式并行能力或未经测试的加速幅度。

计算数据与运行环境不公开。查看相关公开代码 fork ↗；该仓库 fork 自 abhpc/polygr-pfc，上游代码不视为个人原创。

CASE / 03训练与评估已完成

高原眼病筛查：RETFound / PEFT 训练

围绕 15 类疾病的长尾分布，将 RETFound（ViT-Large）与 Adapter / PEFT 结合，完成模型训练、评估和服务联调。

  • 模型方案：参与分层采样、数据增强、参数高效适配与二分类分治训练流程；以 Accuracy、AUC-ROC 和 Macro F1 审视结果。
  • 汇总指标：测试集 Accuracy 89.73%、AUC-ROC 0.935、Macro F1 0.809；指标来自项目实验记录，并非公开数据集基准。
  • 工程协作：参与 RabbitMQ 异步推理和 REST API 联调。相关计算机视觉研究论文仍在投稿阶段。

查看脱敏项目档案 ↗。合作数据、患者图像、权重、训练日志和未发表稿件均不公开。上游模型项目：RETFound ↗。
