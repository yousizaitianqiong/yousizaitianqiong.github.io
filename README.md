# 个人能力展示网页

这是 `@yousizaitianqiong` 的静态个人能力展示页，入口为 [yousizaitianqiong.github.io](https://yousizaitianqiong.github.io/)。

`index.html` 自包含样式、经授权公开的个人照片、GitHub 头像与内容，无构建步骤、第三方脚本或外部资源依赖；可以直接打开，或托管在 GitHub Pages。页面跟随系统浅色或深色设置，流程图呈现 vLLM 通用机制和已完成项目的工程步骤。公开页面使用 GitHub 昵称和 GitHub 联系入口；当前公司工作展示 vLLM 机制研究与汇报，其他经历独立呈现。
